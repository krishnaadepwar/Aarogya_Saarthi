# Aarogya Saarthi – AI Powered Rural Health Companion

## About the Project

Aarogya Saarthi is an AI-powered healthcare platform developed to support rural healthcare management by assisting patients and ASHA workers with intelligent healthcare services. The platform leverages Artificial Intelligence, Machine Learning, OCR, and Retrieval-Augmented Generation (RAG) to provide disease prediction, medicine verification, and healthcare guidance through an interactive chatbot.

The primary objective of Aarogya Saarthi is to improve healthcare accessibility, enhance awareness, and provide preliminary healthcare support in regions with limited medical resources.

---

## Features

- Disease Prediction using Machine Learning models trained on symptom-based healthcare datasets.
- RAG-Based Healthcare Chatbot for context-aware healthcare assistance.
- OCR-Powered Medicine Checker to extract and verify medicine information from uploaded images.
- Role-Based Access Control (RBAC) for Admin, ASHA Worker, and Patient users.
- Secure Authentication and Authorization for user management.
- Centralized healthcare information management system.

## Modules

### Disease Prediction Module

Analyzes user symptoms and predicts potential diseases using machine learning algorithms, enabling early health assessment and awareness.

### Healthcare Chatbot

Provides healthcare-related guidance through a Retrieval-Augmented Generation (RAG) framework that retrieves relevant medical information and generates context-aware responses.

### Medicine Checker

Uses Optical Character Recognition (OCR) to extract medicine names from images and verify medicine-related information automatically.

### User Management System

Supports multiple user roles including Admin, ASHA Worker, and Patient, ensuring secure access and role-specific functionalities.
